# Module compose

Jetpack Compose integration for HaishinKit.

Display a stream with [HaishinKitView][com.haishinkit.compose.HaishinKitView]. Use
[rememberStreamSessionState][com.haishinkit.compose.rememberStreamSessionState] and
[rememberMediaRecorderState][com.haishinkit.compose.rememberMediaRecorderState] to remember
control wrappers with Compose-observable state.
