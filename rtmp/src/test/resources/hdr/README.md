# HLG configuration fixture

`pixel8-hlg-sequence.obu` is the AV1 sequence-header OBU from a synthetic flat-grey
320 × 180, 30 fps frame generated locally on Pixel 8 using `c2.google.av1.encoder`.
It is Main profile, 10-bit, limited-range BT.2020 non-constant-luminance HLG.
No captured camera content is included.
